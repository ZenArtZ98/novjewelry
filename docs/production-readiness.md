# Проверка готовности НОВЬ к публикации

Проверено на 25 сентября 2026 года. Это техническая и экспертная проверка лендинга, а не интервью с покупателями. Сценарии предполагаемого посетителя: найти украшение по форме, сравнить товары, прочитать состав и размер, связаться с брендом, посмотреть страницу с телефона или с клавиатуры.

## Что проверяется автоматически

- Страницы на ширине 320–1440 px: навигация, отсутствие горизонтального переполнения, расстояние между карточками, фильтры, диалог товара, FAQ и движение фотоленты.
- Клавиатура: переход к каталогу, управление диалогом, возврат фокуса и прокрутка фотоленты.
- Доступность: axe-core WCAG 2 A/AA и 2.1 A/AA на ширине 390 и 1440 px, в основных секциях и открытом диалоге.
- Сборка: готовый HTML без JavaScript, генерация 404, robots и sitemap, запрет индексации тестовой сборки, отсутствие ошибок ресурсов и скриптов.
- Публикация: push в отдельную ветку запускает GitHub Actions; публикация из `master` проходит эти же проверки перед выпуском.

Запуск локально: `npm ci`, `npx playwright install chromium`, `npm run check`. Для проверки публикуемой сборки: `VITE_BASE=/novjewelry/ SITE_URL=https://zenartz98.github.io/novjewelry npm run build:release` (в PowerShell задайте переменные через `$env:`).

## Исправлено в ветке

- На телефоне элементы фона первого экрана больше не закрывают заголовок. Их физическая анимация не работает впустую на скрытом мобильном слое.
- Карточки каталога разделены минимум 16 px. Варианты загружаемой фотоленты получают изображения по мере просмотра; её можно прокручивать клавиатурой.
- Текстовые акценты и управляющие элементы используют более контрастные оттенки фирменных цветов. Добавлена ссылка пропуска первого экрана для клавиатуры.
- Шрифт Roboto Serif заменён на WOFF2 с сохранением кириллицы и латиницы. Суммарный размер его двух начертаний уменьшен примерно с 7,9 до 3,1 МБ.
- У серёг унифицирована характеристика «Вес пары». У бирюзовой лошадки указан согласованный вес ~12 г. Для ссылок на страницу добавлено изображение Open Graph.
- Сравнение геометрии в тестах допускает небольшую разницу переноса текста между браузерными платформами, сохраняя проверку размеров и порядка секций.

## Что нельзя подтвердить только кодом

- Настоящий CustDev: понятность слов «ПНД», «конго» и «партия», причины отказа от покупки и удобство оформления заказа нужно проверить на реальных покупателях. Смоделированные сценарии не заменяют такие интервью.
- Ссылка ВКонтакте открывает сообщество. Прямой переход в сообщения и передача выбранного артикула требуют подтверждённого адреса или настройки со стороны сообщества; пока покупателю нужно открыть переписку самостоятельно.
- Стоимость и сроки доставки, остатки, способы оплаты, правила возврата и юридические тексты должны быть сверены с фактической работой бренда перед коммерческой публикацией.
- На GitHub Pages файл `_headers` не применяет CSP и другие HTTP-заголовки, а `robots.txt` проекта не расположен в корне домена `github.io`. Для полного контроля нужен собственный домен и хостинг с настройкой заголовков или прокси.
- Аудит не является гарантией одинакового отображения во всех браузерах и на всех телефонах. После слияния стоит вручную проверить опубликованную страницу на реальных iOS Safari и Android Chrome.
